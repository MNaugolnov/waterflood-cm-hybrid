# waterflood-cm-hybrid

Hybrid proxy model for waterflood analysis: a capacitance model (CM/CRM) for liquid rates,
displacement curves for oil cut, a small neural correction, and an injection-response model
calibrated on observed injection changes. Includes a Dash web interface. Documentation is in Russian.

---

Гибридная прокси-модель заводнения и веб-интерфейс к ней. Исследовательский прототип.

- **Прогноз добычи** по скважинам: ёмкостная модель (CM) для жидкости, характеристики вытеснения
  для доли нефти, небольшая нейросеть как поправка к физической модели.
- **Отклик на перераспределение закачки**: событийная оценка фактического отклика, проверка CM,
  модель отклика, калиброванная по фактическим изменениям закачки, расчёт сценариев.
- **Веб-приложение**: карта связей скважин, прогноз, отклик, сценарии перераспределения. На входе —
  данные добычи, закачки и координаты скважин.

## Быстрый старт

Нужен Python 3.10 или новее (проверялось на 3.13).

```
pip install -r crm_webapp/requirements.txt

cd crm_hybrid_model
python tests/test_synthetic.py
python run_hybrid.py   --data data --blocks S1 --out results
python run_response.py --data data --blocks S1 --out results

cd ../crm_webapp
python tests/test_core.py
python app.py
```

Последняя команда открывает интерфейс на http://127.0.0.1:8050. В списке «Источник» есть готовый
пример.

## Данные

В репозитории только синтетический участок (`crm_hybrid_model/data/Block S1` и
`crm_webapp/sample_data`), его создаёт `crm_hybrid_model/make_synthetic.py`. Модель разрабатывалась
и проверялась на промысловых данных пяти участков действующего месторождения; сами данные не
публикуются, сводные результаты лежат в `crm_hybrid_model/reference_results`.

## Что получилось на реальных данных

1155 скважино-прогнозов на полгода вперёд, 647 резких изменений закачки:

- По отдельной скважине гибрид не лучше инерционного прогноза: медиана ошибки по жидкости 4,8 %
  против 4,7 %.
- Свободный расчёт CM ошибается вдвое сильнее (10,0 %); привязка к последним замерам снижает
  ошибку до 5,2–5,9 %.
- Характеристики вытеснения полезны на уровне участка: ошибка накопленной нефти 5,3 % против
  8,9 % у инерционного прогноза.
- Отклик жидкости на изменение закачки есть, но мал: +1,5 м³/сут на соседнюю скважину на каждые
  +100 м³/сут закачки через полгода. Отклик по нефти статистически не подтверждён.
- CM без калибровки завышает отклик в 2–3 раза. Модель отклика с четырьмя общими параметрами
  предсказывает отдельные события лучше, но объясняет только 12–19 % разброса.

Подробности, таблицы и ограничения — в [README модели](crm_hybrid_model/README.md).

## Состояние

- Расчётная часть покрыта тестами на синтетике с известным ответом.
- Веб-интерфейс проверен на уровне расчётов и обработчиков; как именно это делалось и что не
  проверено — в разделе «Как проверялось» [README приложения](crm_webapp/README.md).
- Забойное давление и ГТМ в модели не учитываются.
